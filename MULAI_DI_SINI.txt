MENJALANKAN DI LINGKUNGAN DENGAN AKSES REGISTRY (Node 24)
1. Ekstrak ZIP; folder berisi package.json adalah root proyek.
2. npx --yes pnpm@11.25.0 install --frozen-lockfile
3. npm run dev:vercel
4. pnpm exec tsc --noEmit
5. npm test
6. npm run build:vercel

Jangan mengulang instalasi jika registry tetap ditolak. Periksa akses jaringan.
Untuk jalur Vinext/Cloudflare, lihat README.md dan konfigurasi aslinya.
