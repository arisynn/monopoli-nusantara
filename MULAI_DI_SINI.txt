2. Upload/push isi folder tersebut ke repository GitHub Anda.
3. Import repository di Vercel atau redeploy proyek lama.
4. Framework: Next.js. Node: 24.x.
5. Install: npx --yes pnpm@11.25.0 install --frozen-lockfile
6. Build: npm run build:vercel
